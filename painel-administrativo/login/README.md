# Login e licenças — Painel Administrativo

Módulo isolado para autenticação administrativa, recuperação do dono, liberação, pausa, reativação e reset de key e diagnóstico de problemas de entrada. `codigo/` preserva cópias exatas da base 1.0.778.

A área `acesso-e-licencas/` continua existindo até a migração dos carregadores. **Não alterar keys reais, permissões ou dados Cloudflare sem validação.**
