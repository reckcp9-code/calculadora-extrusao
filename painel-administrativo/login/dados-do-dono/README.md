# Dados do Dono — Painel Administrativo

Área isolada para localizar as equipes vinculadas à conta do dono, diagnosticar keys, recuperar acesso em novo aparelho, verificar integridade D1/R2, visualizar estado da sincronização e auditar transferências de propriedade.

**Segurança:** autenticação forte para recuperação, permissões por papel, registro de auditoria e bloqueio de acesso a equipes alheias. Key é credencial, não local de armazenamento.

**Status:** módulo de organização criado; nenhuma ação de recuperação de conta foi habilitada ou publicada nesta etapa.
